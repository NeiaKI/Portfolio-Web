Ini post pertama di blog ini. Tulis apa saja di sini menggunakan **MDX** — bisa pakai komponen React, kode, dan markdown biasa.

## Cara tulis post baru

Buat file baru di `content/blog/nama-post.mdx` dengan frontmatter berikut:

```md
---
title: "Judul Post"
description: "Deskripsi singkat untuk preview dan SEO."
date: "2026-05-19"
tags: ["tag1", "tag2"]
published: true
---
```

Ubah `published: false` untuk menyimpan draft tanpa ditampilkan.
