When I decided to rebuild my portfolio, I had one goal: ship something that feels *mine* — fast, clean, and opinionated. Here's what I ended up with and why.

## The Stack

- **Next.js 16** — App Router, Turbopack, React Server Components
- **Tailwind CSS v4** — CSS-first config, OKLCH color system
- **Catppuccin** — Mocha (dark) and Latte (light) themes
- **next-intl v4** — Bilingual support (EN + ID)
- **Supabase** — Database for projects and analytics

## Why Catppuccin?

I've been a Catppuccin user on my desktop (Arch + Hyprland) for over a year. Having the same palette across my terminal, editor, and now website feels cohesive. The OKLCH color model maps perfectly to Tailwind v4's new color system.

```css
:root {
  --background: oklch(0.235 0.015 268);
  --primary: oklch(0.737 0.176 229);
}
```

## Lessons Learned

**Tailwind v4 is a breaking change.** The old `tailwind.config.js` approach is gone. Everything lives in CSS now. It took me a day to migrate but the result is cleaner.

**React Server Components change how you think.** Most of my data fetching happens at the page level — no `useEffect`, no loading states for the initial render. Widgets that need client interactivity (`useTheme`, charts) are isolated into `"use client"` components.

**`next-intl` v4 has a new routing API.** The `createLocalizedPathnamesNavigation` API I was used to is deprecated. The new approach is simpler but the docs lag behind.
